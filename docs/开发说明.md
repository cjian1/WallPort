# 开发说明

给参与开发的人看的说明（面向用户的介绍见仓库根目录的 README.md）。

Mac 上的动态壁纸引擎，Apple 芯片原生。目前做到 **M5：场景特效与粒子**（本机 24 个场景里 23 个完全正常、1 个小缺口，见 `docs/M5-验收清单.md`）。每块屏幕可以单独放一个视频，或者一个含 project.json 的壁纸项目文件夹（视频、网页或场景）。场景目前画图片图层、纯色层、图层混合模式、特效链（WE 着色器在运行时翻译成 Metal）、粒子（含雨滴折射）、合成层、木偶变形图层、文字（含时钟：场景自带的字体用 CoreText 排版，内容由最小脚本宿主算出）和声音对象；脚本跑纯计算的属性脚本、文字脚本，以及用场景对象接口的框架级脚本（幻灯片轮播那种）；每次调用有执行时限，死循环会被终止；鼠标的进入/离开/移动会送给脚本，点击类事件还收不到（桌面窗口本来就忽略鼠标），见 `docs/M5-着色器翻译.md`；场景要用 WE 自带素材，默认从 `~/WallPort/Assets` 读取。没设置的屏幕显示测试图案。系统壁纸会同步成当前画面的静态帧，退出时恢复。

## 构建与运行

需要 macOS 14.6 以上和 Swift 6。场景特效要用的着色器编译器（glslang、SPIRV-Cross）源码随项目一起编译
（见 `Vendor/README.md`），不需要额外安装任何东西。

```bash
swift test
scripts/build-app.sh
open ~/WallPort/WallPort.app
```

`build-app.sh` 默认做 release 构建（粒子模拟在 debug 构建里慢好几倍）；调试时用 `scripts/build-app.sh debug`。
它把 App 装进统一文件夹（默认 `~/WallPort`，`WALLPORT_DIR` 可以改）；App 正在运行时先让它正常退出再换上新的。

发布给别人用的包用 `scripts/release.sh`：Developer ID 签名 + Hardened Runtime + 苹果公证 + `.dmg`（只编 Apple 芯片），
用法和要准备的证书见脚本开头的说明和 `docs/发布准备.md`。

**所有文件都在 `~/WallPort` 里**（见里面的 `说明.txt`）：`WallPort.app`、设置 `Settings.plist`、创意工坊下载的壁纸 `Workshop/`、
WE 自带素材 `Assets/`、登录信息和缓存 `Data/`、`Cache/`、日志 `Logs/`。原来散在 `~/Library/Application Support/MacWallpaper`、
`~/Library/Preferences`、`~/Library/Logs`、`~/Library/Caches`、`~/wp-assets` 和 Steam 的创意工坊文件夹里的，第一次启动时自动挪过来
（`AppFolderMigration`）。命令行工具和测试不读写这里的设置。

运行后菜单栏会出现一个图标。"壁纸库…"列出壁纸文件夹（默认是创意工坊下载的 `~/WallPort/Workshop`，可以添加别的文件夹）里的全部项目：数量、类型、预览图，可以按类型筛选、按标题搜索，点一下就设为所选显示器的壁纸，窗口右侧同时显示这张壁纸的设置——场景和网页壁纸的作者设置（开关、颜色、滑块、幻灯片选哪一张等）直接在那里调，改了立即生效（显示器子菜单的"壁纸设置…"也会打开这里）。菜单里还可以逐屏选择视频、暂停、切换窗口层级、立即自检、打开日志。日志位于 `~/WallPort/Logs/desktop.log`。壁纸默认静音，菜单里的"播放壁纸声音"统一打开视频、网页和场景的声音。

另外几项：

- **轮播**：把壁纸库里的场景、视频、网页按时间自动换（5 分钟到 2 小时，按顺序或随机），只换当前用着项目壁纸的显示器；
- **性能**：帧率上限（30 / 60 / 不限制），以及用电池时的行为（照常 / 降到 15 帧 / 暂停壁纸）；
- **开机自动启动**（以 .app 运行时生效）和**首次使用提示…**（第一次运行自动打开一次）；
- 场景壁纸里作者脚本驱动的幻灯片轮播、跟随鼠标缩放现在会执行；桌面窗口仍然忽略点击，所以拖拽类脚本只停在默认状态。

开发工具：

```bash
swift scripts/make-test-video.swift build/loop-test.mp4
swift run WallpaperTool check-video 视频文件...
swift run WallpaperTool scan 壁纸项目目录
swift run WallpaperTool pkg scene.pkg...
swift run WallpaperTool tex 纹理.tex...
swift run WallpaperTool steam-manifest 清单.manifest [已下载目录]
swift run WallpaperTool steam-ugc 清单.manifest 输出目录 --depot 431960 --host <CDN> --key-env <变量>
swift run WallpaperTool steam-cm --cm-auth <账号名>          # 登录整条走 CM（密码在终端输入，要手机确认）
swift run WallpaperTool steam-cm --cm-auth-qr --qr /tmp/qr.png  # 扫码登录（不用密码）
swift run WallpaperTool steam-workshop --list --qr /tmp/qr.png               # 我的订阅（走 CM）
swift run WallpaperTool steam-workshop 3807008481 /tmp/out --qr /tmp/qr.png  # 原生下载（不用 SteamCMD）
swift run -c release WallpaperTool bench-scenes ~/wp ~/wp-assets             # 每个动态场景每帧的 CPU / GPU 时间
BENCH_REALTIME=15 BENCH_FPS=120 swift run -c release WallpaperTool bench-scenes 目录 ~/wp-assets  # 按真实时间跑，看主线程会不会被卡住
swift run -c release WallpaperTool motion-scenes ~/wp ~/wp-assets            # 每个动态场景会被自动帧率定成几帧
swift run -c release WallpaperTool effect-variants ~/wp ~/wp-assets /tmp/v   # 场景包里各版本的内置特效着色器
scripts/capture-projects.sh 输出目录 项目文件夹...
```

依次是：生成检查循环接缝用的测试视频；批量检查视频能否被系统播放；扫描一个目录下的全部壁纸项目（类型、预览图、场景包内容和依赖）；查看 scene.pkg 的条目；核对 TEX 纹理的格式；解析创意工坊的清单；不靠 SteamCMD 从内容服务器下载并拼出创意工坊内容（`--verify <目录>` 可以和 SteamCMD 下好的那份逐字节比对）；在 CM 上跑完整的登录（M7.5）；不靠 SteamCMD 完成"登录 → 条目详情 → 我的订阅 → 下载"整条创意工坊流程（M7.5）；量每个动态场景在屏幕尺寸上每帧的 CPU / GPU 时间（找最费电的场景，见 `docs/性能与能耗.md`）；
量每个动态场景的画面动得多快、自动帧率会定成几帧（`MOTION_DEBUG=<目录>` 存每次测量的分块诊断图）；
列出场景包里各版本的内置特效着色器指纹和源码（给"特效只在图层内容附近算"核对新版本用）；
把项目逐个放到桌面上跑，收集日志、截图和资源占用。

### 关于文件访问授权

壁纸文件放在"文稿""桌面""下载"或外置盘里时，macOS 会询问是否允许访问。系统按签名身份记住授权；`build-app.sh` 在没有证书时用临时签名，每次构建签名都会变，所以每次都要重新允许。在 Xcode → 设置 → 帐户里登录 Apple ID 生成免费的 Apple Development 证书后，脚本会自动用它签名，只需授权一次。开发时也可以把测试壁纸放在 `~/Library/Application Support/MacWallpaper/dev/`，这个位置不受保护。

## 目录

| 路径 | 内容 |
|---|---|
| `Sources/DesktopHost` | 呈现层：桌面层窗口、显示器同步、窗口自检、诊断日志 |
| `Sources/VideoWallpaper` | 视频壁纸：硬件解码、无缝循环、遮挡时暂停 |
| `Sources/WebWallpaper` | 网页壁纸：WKWebView、WE 网页壁纸接口兼容层 |
| `Sources/WallpaperLibrary` | 逐屏的壁纸分配、project.json 解析 |
| `Sources/WallpaperFormats` | WE 文件格式：scene.pkg、TEX 纹理、scene.json、场景依赖分析 |
| `Sources/ShaderTranslation` | WE 着色器方言：读接口、拼装、改写成可编译的 GLSL |
| `Sources/ShaderCompiler` | 进程内调用 glslang / SPIRV-Cross，把 WE 着色器翻译成 Metal |
| `Sources/SceneRenderer` | 场景渲染：纹理上传、图层绘制、图层混合模式、特效链、桌面上的场景内容 |
| `Sources/SteamProtocol` | Steam 客户端协议：CM 的 WebSocket 连接与登录、服务方法调用、UGC 分块的解密/解压/拼装 |
| `Vendor/` | 随项目一起编译的第三方源码（glslang、SPIRV-Cross、zstd 解压器），见 `Vendor/README.md` |
| `Tests/Fixtures` | 自己编写的测试夹具（不含任何 WE 内容） |
| `Sources/MacWallpaperApp` | 菜单栏应用外壳和测试图案 |
| `Sources/WallpaperTool` | 开发用命令行工具 |
| `Tests/` | 单元测试 |
| `docs/` | 各里程碑的验收清单 |
| `REFERENCES.md` | 每个技术点的知识来源，新增技术点时必须追加 |
