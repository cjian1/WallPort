# M2 网页壁纸：验收清单

计划里的验收标准是**至少 5 个常见的网页壁纸正常运行**。

## 已实现

- 菜单栏 → 显示器 → "选择壁纸项目文件夹…"，读取 project.json，按类型放视频或网页；场景和应用程序类会说明不支持的原因；
- 页面经自定义协议 `wallpaper://project/` 加载，页面里的 fetch/XHR 读同目录文件是同源的，访问范围限制在项目文件夹内；支持 Range 请求（页面里的视频可以拖动和循环）；
- 兼容层：`wallpaperPropertyListener` 的 `applyGeneralProperties`（fps）、`applyUserProperties`（加载时带全部属性）、`setPaused`；`wallpaperRegisterAudioListener` 等注册函数可以调用但暂时没有数据；
- 按 30 fps 节流 `requestAnimationFrame`（与告诉页面的 fps 一致）；暂停时冻结动画回调，不理会 `setPaused` 的页面也会停下；
- 页面的 console 输出和脚本错误写进诊断日志（每个页面最多 200 条）；
- 数据不落盘；不允许弹窗和主页面跳走；菜单里可以整体禁止网页壁纸联网；
- 页面进程崩溃后自动重新加载，最多 3 次；
- 项目在后台读取：项目放在"文稿""下载"等受保护位置时，系统会询问访问权限，询问期间菜单栏仍然可用，桌面显示"正在读取项目…"。

## 真实项目验收（2026-09-28，`~/wp` 里的 7 个网页壁纸，用 `scripts/capture-projects.sh` 批量跑）

| 项目 | 结果 |
|---|---|
| 加载 | 7 / 7 加载完成，日志里没有脚本错误 |

## 已知限制

- **没有音频数据**：音频可视化类壁纸能加载，但不会随音乐动。下一步接 Core Audio tap；
- **不能交互**：桌面窗口不接收鼠标，依赖鼠标位置或点击的壁纸没有反应；
- 媒体集成（正在播放的歌曲）、目录类属性、`wallpaperRequestRandomFileForProperty` 暂时没有数据；
- 暂停只冻结动画回调，页面里的定时器（setInterval）仍在运行；
- localStorage 不跨重启保存。
