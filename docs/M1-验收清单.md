# M1 视频壁纸：验收清单

M1 的目标是**能作为日常壁纸连续使用一整天**。

## 已实现

- 每块显示器单独选择视频（菜单栏图标 → 显示器 → 选择视频…），设置按显示器 UUID 保存，重启后保留；
- AVFoundation 硬件解码、静音、`AVPlayerLooper` 无缝循环，按比例铺满裁切；
- 不阻止显示器休眠；
- 窗口被完全遮挡（全屏应用、锁屏、屏幕睡眠）持续 1 秒后暂停，露出来立即恢复；
- 全部暂停 / 单屏暂停；
- 选文件时先检查能否播放，WebM 等格式直接拒绝并说明原因；运行中文件丢失或解码失败时，退回测试图案并显示原因。

## 已自动验证（2026-09-28，macOS 27.0，M2 Pro 内建屏）

| 项目 | 结果 |
|---|---|
| 1080p H.264 测试视频播放与循环 | 正常，每 4.1 秒循环一次 |
| 从载入到开始播放 | 冷启动第一次 5.6 秒，之后不到 10 毫秒 |
| 播放时 CPU | 约 2.3% |
| 内存占用（footprint） | 16–17 MB |
| `WallpaperTool check-video` | 正确放行 mp4，拒绝 WebM、伪造的 mp4 和不存在的文件 |
| 5 个真实视频项目（`~/wp`） | 全部可以播放：都是 H.264，4 个 3840×2160 60 帧、1 个 4096×2412 带音轨；时长 2.7–12 秒，没有 WebM |
| 4K 60 帧视频的占用 | 系统解码服务约 7%，应用约 4.4% |
