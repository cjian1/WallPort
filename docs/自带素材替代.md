# WE 自带素材：打包，还是自己写一套（2026-09-30）

场景壁纸要用 Wallpaper Engine 安装目录里的 `assets`（着色器、贴图、字体……）。现在要用户从 Windows 上的 WE 拷过来，
只有 Mac 的用户拿不到。两条路：把 WE 的素材打包进壁坞，或者自己写一套能替代的。
**法律方面的判断不是法律意见，正式发布前请律师看一遍。**

## 结论

- **不能把 WE 的素材打包进去。** 这些着色器、贴图、粒子预设是 WE 开发者的作品，WE 的用户协议不允许拿去分发。
  现在的做法是"用户用自己已有的一份"，打包则是壁坞自己把 WE 的文件发给所有下载的人（包括没买 WE 的人），
  是直接的侵权，网站会收到下架通知，Steam 更不可能上架。唯一的例外是拿到 WE 开发者的书面授权。
- **自己写一套可行，而且量不大**：本机 347 个场景实际只用到 WE 素材里的 76 样、81 个文件（见下）。
  写好以后：导入了 WE 素材的用户画面和 WE 完全一致；没有 WE 素材的用户用壁坞自带的兼容素材，大部分场景照样能放，
  粒子贴图这类"画出来的东西"会和原版长得不一样。

## 进度（2026-10-01）

目标定为"播放用的全套"（不做编辑器素材库）。已经做完，代码在 `Sources/SceneRenderer/Compat/`：

| 部分 | 做法 | 和 WE 对照 |
|---|---|---|
| 公共头文件 7 个 | 自己写；约定用 `probe-effect` 黑盒量（模糊核是 σ = 2 的积分高斯 + 线性采样，`M_PI_2` 是 2π，灰度权重是 0.11/0.59/0.30，混合模式按 `BLENDMODE` 开关……） | 逐像素一致（`blur7a` 左右不对称的那点差 3e-4，没复现） |
| 粒子着色器 genericparticle | 自己写；`probe-particle` 逐项量（大小、高宽比、三轴旋转、拖尾、精灵图选帧、R8/RG88、挖空、折射） | 单粒子对照全部逐像素一致 |
| 泛光四步 | 自己写；提亮公式对照画面拟合（误差在 8 位量化以内），模糊 σ = 2.3 | 差 1–4/255 |
| 图层模型 6 个 | 只写壁坞要看的标记 | 一致 |
| 贴图 56 张 | 程序生成：尺寸、格式、平铺、精灵图帧布局和 WE 一样，内容自己画（噪声按统计特性） | 样子不同（预期） |
| 字体 15 个 | 许可证允许再分发、能从原作者处取得的带原字体（Roboto Mono、Noto Sans、Blackout、Segment7）；其余换外观相近的开源字体（Pixelify Sans、Quicksand、Poppins、DSEG14、Knewave、Victor Mono……），表情字体用系统字体。文件在 `App/CompatFonts`（来源、许可证、为什么换见那里的 README），打包时拷进 App | 原字体一致；替代字体样子相近 |

本机 330 个场景（`compat-check`）：
- 只换代码、贴图仍用 WE 原版：230 个逐像素一致，88 个最大差 1/255，6 个差 2–5，5 个差得多一些（泛光、7 格模糊）；
- 完全不给 WE 素材：330 个全部能放（8 个时钟用的字体后来也补上了，见上表）。

工具：`asset-usage`（场景用到哪些素材）、`compat-check`（对照）、`probe-effect` / `probe-particle` / `probe-scene`（黑盒量行为）、
`tex-stats`（贴图统计量）、`compat-textures`（把生成的贴图导出成 PNG 看）。

## 场景实际用到了什么

`WallpaperTool asset-usage <目录> <WE 自带素材目录> [输出.json]` 逐个构建、渲染场景（第 0、3 秒），
记下从素材目录读到的每个文件（着色器注释里的默认贴图、特效文件夹里的文件、脚本建的图层都算在内）。

本机 347 个场景：31 个完全不用自带素材；其余用到的合起来 76 样：

| 类别 | 数量 | 说明 |
|---|---|---|
| 粒子着色器 genericparticle + 它引用的 3 个头文件 | 4 样 | 217 个场景有粒子 |
| 公共头文件（common.h、common_blending.h、common_perspective.h、common_blur.h……） | 7 样 | 特效本身都在场景包里（WE 发布时拷进去，264 个包带了特效着色器），但它们 `#include` 这些头文件 |
| 场景泛光的 4 个着色器 | 4 样 | 11 个场景开了泛光 |
| 贴图 | 51 样 | 纯色、噪声、云、渐变 5 样；其余是粒子贴图：光斑、光束、雾、烟、水滴、花瓣、树叶、碎片、火焰、雪…… |
| 字体 | 6 样 | 都是第三方字体（WE 只是附带），有各自的许可证 |
| 内置图层的模型 JSON（composelayer、solidlayer、fullscreenlayer、projectlayer） | 4 样 | 每个只有几十字节，描述"这是合成层 / 纯色层" |

公共头文件里，场景包的着色器实际用到的只有二十来个名字（按"场景包着色器里出现、WE 头文件里声明"统计，
只看名字不看实现）：`M_PI`、`M_PI_2`、`rotateVec2`、`hsv2rgb`、`rgb2hsv`、`greyscale`、`ApplyBlending`
（按开关选混合模式）、`BlendOpacity`、`BlendLinearDodge`、`squareToQuad`、`inverse`、`blur3a/7a/13a`、
`ApplyComposite`、`ApplyCompositeOffset`、`FORMAT_R8`、`FORMAT_RG88` 等。都是公开的标准数学：
π、二维旋转、HSV 换算、Photoshop 式混合模式（壁坞的图层混合已经有自己写的 Metal 版本）、四边形透视映射（Heckbert）、高斯模糊核。

按做法分档，做完每一档时"不缺自带素材"的场景（本机 347 个）：

| 档 | 内容 | 场景 |
|---|---|---|
| 1 | 自己写的代码：粒子着色器、泛光、公共头文件；纯色 / 噪声 / 云 / 渐变贴图程序生成；4 个图层模型 | 118（34%） |
| 2 | 程序生成的粒子贴图：光斑、光束、光晕、雾、烟、气泡、闪电、水滴、雪 | 274（79%） |
| 3 | 要画的粒子贴图：花瓣、树叶、碎片、火焰（自己画，或用 CC0 素材，例如 Kenney 的粒子包） | 338（97%） |
| 4 | 字体：从原作者处按各自许可证取得，或换成相近的开源字体 | 347（100%） |

"不缺"不等于"一模一样"：代码部分照数学写可以做到和 WE 一致；贴图是自己做的，噪声的随机图案、粒子的样子会不同。
这是一个用户的 347 个场景，别人的场景可能用到这 76 样以外的素材（WE 的 materials 里有 586 个文件），
缺的照现在的办法跳过；之后可以按反馈补。

## 怎么做才算"自己写"

- 不拷贝、不逐行翻译 WE 的代码和贴图。和 WE 一样的只有**接口**：文件路径、函数名、参数名和含义——
  不一样就读不了现有的壁纸。实现按公开的数学定义写；
- 拿 WE 的原版素材只做**对照测试**（在开发机上渲染对比画面），不进仓库、不进安装包；
- 每个兼容素材在仓库里记一笔来源（自己写的 / 程序生成的参数 / CC0 素材的出处和许可证）。

## 放在哪、怎么用

- 兼容素材放进 App 包（`Contents/Resources/CompatAssets/`），目录结构和 WE 的 assets 一样；
- 找文件的顺序：场景包 → 用户导入的 WE 素材 → 壁坞自带的兼容素材；
- 欢迎页的第 2 步（导入 WE 自带素材）变成可选："有 WE 的话导入，画面和 WE 完全一致"。

## 如果要做"全部"

WE 的 assets 目录约 2900 个文件，但一大半是**编辑器**用的（在 WE 里做壁纸时的素材库），播放壁纸从来不读：

| 部分 | 数量 | 播放壁纸要不要 | 做法 |
|---|---|---|---|
| 特效 | 46 个（122 份版本定义、173 组着色器、74 张遮罩 / 噪声图） | 基本不要：发布时拷进场景包，本机 347 个场景一次也没读过；只当旧场景的兜底 | 逐个按效果写自己的着色器和参数定义，对照 WE 的画面 |
| 着色器 | 约 45 个运行时 + 12 个头文件；另有约 12 个编辑器专用 | 头文件、粒子、泛光要；图片层壁坞已自己实现；3D 模型、毛发、植被、阴影、体积光是 3D 场景用的 | 自己写 |
| 贴图 | 粒子 164、工具 9（+62 份材质定义）、渐变 16、调色 LUT 28、光照遮罩 4、图案 2 | 要：这些 WE 不拷进场景包 | 纯色、渐变、LUT、噪声程序生成；粒子贴图约三分之一能程序生成，其余要画或用 CC0 素材 |
| 字体 | 19 个文件（第三方字体） | 要 | 按原许可证取得或换开源字体 |
| 脚本模块 | 4 个（WEMath、WEVector、WEColor、基类） | 要：场景脚本会 import（壁坞还没实现） | 自己写 |
| 图层模型、兼容垫片 | 7 + 11 | 部分要 | 自己写 |
| 粒子 / 特效预设 | 880 | **不要**：编辑器"添加素材"的库，用到的在发布时变成场景自己的文件 | 只有做编辑器才需要 |
| 编辑器场景、编辑器材质 | 244 + 31 | 不要 | 只有做编辑器才需要 |

- 目标是"任何创意工坊壁纸都能放"：做播放用的全套就够了。顺序：实测要用的 76 样 → 其余粒子贴图、渐变、LUT、字体、
  脚本模块 → 46 个特效兜底 → 3D 场景的着色器。代码部分工作量可控，大头是一百多张要画的粒子贴图；
- 目标是"在 Mac 上也能做壁纸"（编辑器）：那是另一个产品，素材库（预设、模板）应该自己设计、自己起名，
  不要照着 WE 的 880 个预设一一复刻——兼容只要求现有壁纸里出现的路径和参数一致，编辑器素材库不在其中，
  照搬它们的参数值、照着它们的贴图逐张重画，就从"兼容"变成"复制"了。

## 建议的顺序

1. 第 1、2 档：都是代码和程序生成，不用下载任何东西，做完覆盖本机 79% 的场景；
2. 第 3 档：先定贴图来源（自己画 / CC0 素材包 / 请人画）；
3. 第 4 档：逐个核对字体许可证，能附带的从原作者处下载，不能的换开源字体。
