# M4 场景运行时最小版：验收清单

计划里的验收标准：**渲染出一个只有图片层的场景。**

## 已实现（`Sources/SceneRenderer`）

- `SceneDescription`（格式层）：把 scene.json 解析成对象列表，统一处理 `{"value"/"user"/"script"}` 等写法；
- `TextureLoader`：DXT1/3/5 直接作为 BC 压缩纹理上传；R8/RG88/RGBA8888 原样上传；内嵌 JPEG/PNG 用系统解码，超过 4096 的缩小，带透明度的还原成非预乘；纹理有补齐边距时按"图像尺寸 / 纹理尺寸"缩小采样范围；
- `SceneRenderer`：图片图层、纯色层、分组的父子变换、可见性继承、透明度、颜色、材质的透明/叠加混合、**29 种图层混合模式**（用 Apple GPU 的可编程混合读帧缓冲实现）、正交画布按"铺满裁切"适配屏幕；
- `SceneContent`：后台线程构建场景，CAMetalLayer 显示；M4 的场景没有动画，只在尺寸变化或重新露出时重画；支持截图，系统壁纸同步照常工作；
- 菜单：可以选择场景项目；"WE 自带素材目录"默认用 `~/wp-assets`；
- 暂不支持的内容逐项统计并写进日志，不会静默丢掉；
- 命令行：`WallpaperTool render-scenes <目录> <素材目录> <输出目录>` 离屏渲染全部场景，并和项目自带的预览图比较。

## 验收结果（2026-09-28，`~/wp` 的 24 个场景）

| 项目 | 结果 |
|---|---|
| 离屏渲染 | 24 / 24 成功，单个场景构建 0.01–1.3 秒 |
| 坐标方向 | 与预览图比较，24 个里 18 个不翻转更接近；Everyone 分级的场景人工看过，地面在下、天空在上 |
| 图层混合模式 | Lucy 场景里的"滤色"光晕和"柔光"彩虹叠加正确；修复前按普通方式画会出现大块黑色 |
| 桌面运行 | Lucy 场景：构建 0.46 秒，画 8 层，静止时 CPU 0.0%，内存 141 MB |

注意：项目自带的预览图是作者自己框选的局部，不一定居中，所以相似度只能粗略参考。准确的比对需要 Windows 上的全屏截图。

## 实测确认的约定

- 正交场景的画布原点在左下角，y 轴向上；对象的 origin 是图层中心；
- `g_TextureNResolution` 是 (纹理宽, 纹理高, 图像宽, 图像高)：WE 图片着色器的顶点程序里就是用 zw / xy 缩放纹理坐标的；
- 图层混合模式的编号和含义见 WE 自带素材 `shaders/common_blending.h`：1 变暗、2 正片叠底、3 颜色加深、4/20 线性加深、5 深色、6 变亮、7 滤色、8 颜色减淡、9 相加、10 浅色、11 叠加、12 柔光、13 强光、14 亮光、15 线性光、16 点光、17 实色混合、18 差值、19 排除、21 反射、22 发光、23 凤凰、24 平均、25 否定、26 色相、27 饱和度、28 颜色、29 明度。
